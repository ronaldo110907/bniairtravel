# 장가계 2027 좌석현황 연동

- 상품: `products.slug = zhangjiajie-2027` (기존 장가계/하문 상품 제외)
- 기간: 2027-03-01 ~ 2027-06-30
- 시트: https://docs.google.com/spreadsheets/d/1eaDSwD9IxjuOQkqQxc-Ow2XgUrFcxcDMyy0HfC1wrJo/edit
- 탭: `좌석현황`, B열 날짜(yyyy-mm-dd) + D열 패턴으로 매칭
- 상단 제목 1~2행, 머리글 3행, 출발일 4행부터. 코드가 날짜/패턴 머리글을 찾아 실제 시작 행을 결정한다.
- 관리자가 확정한 66항차를 기준으로 홈페이지와 날짜/패턴을 일치시켜야 한다.

## 갱신 범위

G(홀드), H(모객확정)만 갱신한다. 대기/홀드는 G, 확정만 H에 합산하고 취소는 제외한다.
좌석 인원은 `max(people_count, 실제 등록 인원, 1)`이며 인솔자도 포함한다.
E(금액), F(총좌석), I(잔여석 수식), J(비고)와 서식은 보존한다.
총좌석을 조정할 때는 시트 F열도 직접 수정한다. I열은 `F-G-H`로 계산하며 음수도 유지한다.
시트와 DB에 누락/중복/패턴 차이가 있거나 알 수 없는 예약 상태가 있으면 쓰기 전에 전체 중단한다.
시트 정렬을 바꿔도 날짜/패턴을 기준으로 해당 행에 기록한다.

## 실행 및 배포

- 기존 `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY`, Supabase 서버 환경변수, `CRON_SECRET`을 그대로 사용한다. 별도 환경변수 추가 불필요.
- 기존 서비스 계정에 새 시트 편집 권한을 부여했다. 일반 외부 공개 설정은 변경하지 않았다.
- 수동: 관리자 공통 `구글시트 좌석 동기화` 버튼 → 하문/장가계 각각 실행하고 성공/실패를 개별 표시.
- 자동: Vercel `/api/cron/zhangjiajie-seat-sync`, `5 8 * * *` (한국시간 매일 17:05).
- 하문은 기존 매일 17:00 유지. 실시간 연동이 아니다.
- 배포 후 Vercel Cron 등록 및 첫 실행 성공을 확인해야 운영 자동 연동 완료이다.
- 서버 관리자 인증 또는 Cron 비밀값 인증에 성공한 요청만 실행한다.

실제 예약을 테스트 목적으로 생성/수정하지 않는다.
